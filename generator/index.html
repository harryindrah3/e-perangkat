PEMASANGAN SEKALI SAJA

Hubungkan Chrome Anda

Ekstensi memakai halaman cetak asli, termasuk logo dan tanda tangan yang tersimpan di browser.

Unduh ekstensi ↓
  1. Ekstrak ZIPUnduh ekstensi, klik kanan file ZIP, lalu pilih Extract All / Ekstrak Semua.
  2. Buka pengaturan ekstensiKetik chrome://extensions di bilah alamat Chrome. Aktifkan Developer mode / Mode pengembang.
  3. Muat folderKlik Load unpacked / Muat yang belum dikemas. Pilih folder hasil ekstrak yang berisi manifest.json.
  4. Kembali ke generatorMuat ulang halaman ini. Buka E-Perangkat pada browser yang sama, lalu klik Ambil data pesanan.

Saat membuat PDF, Chrome menampilkan pemberitahuan debugging. Izin ini dipakai untuk menjalankan mesin cetak Chrome. Data pesanan diproses di browser, bukan dikirim ke server generator.

Perbarui ekstensi ke versi 1.0.3

Versi lama dapat menghentikan dokumen besar atau membatalkan unduhan karena perbedaan jumlah halaman. Unduh pembaruan 1.0.3, ekstrak dan salin isinya ke folder ekstensi yang dipasang sebelumnya (timpa file lama). Buka chrome://extensions, klik tombol muat ulang pada Genarator E-Perangkat, lalu muat ulang halaman ini.

Unduhan sesi ini

    Cara kerja & batas pemeriksaan

    Ekstensi membuka salinan sementara halaman cetak E-Perangkat dengan data pesanan terpilih. Font, isi, CSS cetak, dan ukuran kertas berasal dari halaman asli. Mesin cetak Chrome membuat PDF tanpa menyusun ulang dokumen menjadi gambar.

    Generator menunggu font, gambar, serta pembagian halaman selesai, lalu membandingkan jumlah halaman PDF dengan halaman pratinjau. Jika berbeda, PDF utuh tetap diunduh dan perbedaannya ditampilkan untuk diperiksa. Pemeriksaan ini tidak menjamin seluruh isi bebas tumpang tindih; kualitas tata letak tetap mengikuti halaman asli. Hasil paling dekat dengan cetak manual pada Chrome yang sama dengan skala 100%, tanpa header/footer browser, dan grafik latar diaktifkan.

    Ekstensi tidak mengubah status pembayaran atau pesanan. Tab cetak sementara memblokir sinkronisasi database. Jika ekstensi belum dipasang atau dinonaktifkan, generator belum dapat membuat PDF. Untuk Chrome desktop; belum untuk browser ponsel.
