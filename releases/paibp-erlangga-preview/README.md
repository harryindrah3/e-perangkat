# Preview PAI BP Versi Erlangga A–C

Branch ini khusus **preview** dan tidak mengubah production.

- Menambahkan 3 aplikasi baru: Fase A, B, C.
- Mencakup Kelas 1–6.
- Struktur bab/subbab mengikuti foto daftar isi buku PAI BP Erlangga yang diberikan pengguna.
- CP tetap mengacu pada CP PAI dan Budi Pekerti 2026.
- Modul, tujuan, aktivitas, diferensiasi, asesmen, bahan ajar, LKPD, dan pertanyaan dikembangkan secara orisinal sesuai cakupan bab/subbab; bukan salinan verbatim buku.
- Aplikasi PAI BP reguler tetap terpisah dan tidak ditimpa.
- Storage pesanan versi Erlangga memakai key tersendiri.


## Validasi build
- Fase A: 20 bab/modul (Kelas I 10, Kelas II 10), 54 JP per semester per kelas.
- Fase B: 22 bab/modul (Kelas III 11, Kelas IV 11), 54 JP per semester per kelas.
- Fase C: 20 bab/modul (Kelas V 10, Kelas VI 10), total semester mengikuti alokasi aplikasi PAIBP saat ini (V 78 JP, VI 76 JP).
- Setiap modul memuat daftar subbab Erlangga, tujuan, ringkasan materi, diferensiasi, kegiatan per pertemuan, asesmen, pertanyaan, bahan/LKPD metadata, dan catatan sumber.
